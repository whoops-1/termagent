# Review

## Use this skill when
- The user asks for a focused review of a small code change.

## Procedure
1. Read the relevant files.
2. Identify concrete correctness or compatibility risks.
3. Report evidence and verification steps.

## Examples
- In scope: review a changed helper function.
- Out of scope: unrelated feature implementation.

## Self-check before responding
- Every finding has an inspected file or symbol behind it.
- The response distinguishes facts from suggestions.
