# Phase 16C — Notebook and structured-document editing (deferred specification)

**Status:** Deferred indefinitely from the active Phase 16 selection as of 2026-11-01. No implementation is authorized in the current roadmap.

The preserved scope is: research notebook-aware editing and the `NotebookEdit`-style interaction model; define a cell-aware document/mutation contract; preserve cell history, execution/output state, diff/review semantics; and implement a genuine notebook-aware editor rather than treating notebooks as ordinary text files.

Reopen only when a concrete TermAgent workflow requires notebook editing and the document-state, execution and review lifecycle can be specified without weakening current session/checkpoint semantics.
