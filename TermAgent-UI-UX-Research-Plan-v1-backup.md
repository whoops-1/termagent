# TermAgent UI/UX Research & Freeze Plan — Archived Draft

This file is retained as an historical design draft. It predates the completed 13N-I visual-system pass and is no longer the authoritative UI specification.

The current design is documented in `TermAgent-UI-UX-Research-Plan.md`.

The draft established several durable goals that remain useful:

- semantic rather than decorative hierarchy;
- one shared geometry policy for terminal surfaces;
- responsive layouts for narrow Termux screens;
- explicit keyboard and mouse ownership;
- structured picker rows with global selection and scrolling;
- user-message separation from the composer;
- shared diff rendering;
- semantic themes instead of hard-coded colors;
- asynchronous agent activity without blocking the composer.

Completed implementation details and current regression expectations belong in the active plan and phase reports, not in this archived draft.
