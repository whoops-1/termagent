A coding agent that lives in your terminal

TermAgent plans, edits, runs tools and verifies changes from a single prompt. Its runtime core has zero npm dependencies, so it installs and runs anywhere Node 22 runs — including Termux on an Android phone.

Install TermAgent View source

npm install -g @whoops-1/termagent — no native modules, no postinstall scripts.

Terminal demo: npm install -g @whoops-1/termagent, then run termagent to start the agent.
termagent — install demo

Install

Real commands, every shell

One package, one command. Pick your shell below — every snippet is copy-paste ready and nothing here is a placeholder.

C:\> node --version

Must print v22.x or newer — TermAgent requires Node.js ≥ 22.

C:\> npm install -g @whoops-1/termagent
C:\> termagent

The commands are identical in cmd.exe and PowerShell — only the prompt differs.

PS C:\> npm install -g @whoops-1/termagent
PS C:\> termagent

Same in Windows PowerShell 5.1 and PowerShell 7+. Node.js ≥ 22 is required — winget install OpenJS.NodeJS.LTS installs it.

$ npm install -g @whoops-1/termagent
$ termagent

Works on macOS, Linux and Termux. On Termux, start with pkg install nodejs, then the same two commands. Requires Node.js ≥ 22.

$ git clone https://github.com/whoops-1/termagent
$ cd termagent
$ npm install
$ npm run build
$ npm link
$ termagent

Builds the TypeScript runtime into dist/ and links the termagent bin globally. This is how you run main-branch code or contribute.

Why TermAgent

Built for real terminals

A zero-dependency runtime core with mature capabilities — not a toy that happens to print ANSI.

  • Terminal-first coding agent

    Describe a change; TermAgent plans, edits files, runs tools and verifies the result — all from your prompt line.

  • Termux & ARMv7 ready

    A pure-JavaScript core with no native modules, designed to install and run on Android phones through Termux.

  • Web View client

    Pair a browser as a peer client: sessions, transcripts, permissions and diffs in a dark, phone-friendly UI.

  • Skills & plugins

    Extend the agent with skill packages and marketplace plugins, loaded through an explicit trust model.

  • Daemon & durable tasks

    Long work runs in background workers with durable task state that survives restarts and client reconnects.

  • Zero runtime dependencies

    The core runtime ships with no npm dependencies — nothing extra to audit, update or break on a constrained device.

How it works

Three steps to a working agent

No accounts, no daemons to babysit, no dashboard. Install, connect a provider, describe a change.

  1. 1

    Install

    Grab the CLI with npm install -g @whoops-1/termagent, or build from source. Node.js 22+ is the only requirement.

  2. 2

    Connect

    Add your model provider key to a TermAgent config file — start from .termagent-example.json in the repository — then launch termagent.

  3. 3

    Run

    Open a project, describe a change and approve edits as they arrive. Sessions are durable: checkpoints, undo and replay included.
